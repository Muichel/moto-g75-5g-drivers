# moto-g75-5g-qualcommdrivers
this repository contains the qualcomm proprietary drivers, extracted from moto g75 5g

# Device info:

* Soc: snapdragon 6 gen 3
* Gpu: Adreno 710
* Android version: 16
* driver version: 512.800.55

# important:
* When the firmware gets a new update that changes the version, i will upload in the releases page; so the current version won't get deleted.
* Probably it will be bimestral, but gpu drivers have the chance to NOT get an update.
